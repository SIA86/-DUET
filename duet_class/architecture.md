# Architecture: DUET (Dual Clustering Enhanced Time Series Classification)

## Overview

DUET — архитектура для **классификации многомерных временных рядов**, спроектированная для данных, которые одновременно обладают:

1. **Временной неоднородностью** — разные сегменты временного ряда могут соответствовать разным режимам, состояниям или распределениям.
2. **Сложной межканальной структурой** — зависимости между каналами могут быть частично полезными, частично шумовыми.

Для решения этих проблем DUET использует **двойную кластеризацию**:

* кластеризацию по времени (Temporal Clustering),
* soft-кластеризацию каналов (Channel Clustering) в частотной области,

и объединяет результаты через **masked fusion**, после чего формируется представление всего временного ряда для классификации.

---

## Problem Definition

На вход подаётся окно многомерного временного ряда:

* входной тензор:
  `X ∈ R^{B × L × C}`

где
`B` — размер батча,
`L` — длина временного ряда (или окна),
`C` — число каналов (переменных).

Цель модели — предсказать класс временного ряда:

* выход модели:
  `logits ∈ R^{B × K}`

где `K` — число классов.

---

## High-Level Pipeline

Архитектура DUET для классификации состоит из следующих этапов:

1. Подготовка временного ряда (`prepare_and_check.py`)
2. Нормализация входного временного ряда
3. Temporal Clustering Module (TCM)
4. Channel Clustering Module (CCM)
5. Fusion Module (FM)
6. Classification Head

Все компоненты обучаются end-to-end.

---

## 0. Data Preparation (`prepare_and_check.py`)

Перед подачей данных в модель используется единый подготовщик `FinancialTimeSeriesPreparer`:

* `timestamp_col="timestamp"` — построение `DatetimeIndex` из колонки времени.
* `tz="UTC"` — нормализация временной зоны.
* `ensure_ohlcv=True` — приведение имён OHLCV и отчёт о пропущенных колонках.
* `drop_warmup=True` — удаление префикса «прогрева» для rolling‑признаков.

Подготовщик также:

* удаляет дубликаты по времени,
* восстанавливает регулярную частоту и помечает `gaps`,
* заполняет пропуски по правилам (ffill/0/target не трогает),
* добавляет диагностические флаги `nan_filled` и `candle_error`.

---

## 0.1 Data Slicing & Splitting (`wf_slicer.py`)

Нарезка и разбиение данных выполняются через `WalkForwardWindowSlicerVec`:

* `SplitConfig` задаёт walk‑forward разбиение на `train/val/test` (доли, режим `expanding/sliding`, `gap` для embargo).
* `WindowConfig` описывает X/Y‑окна относительно якоря `t0` (длины и смещения `x_end_offset`, `y_end_offset`).
* `GlobalNormConfig` управляет глобальной нормализацией (опционально), а `no_norm_cols` исключает колонки из скейлинга.

Выход slicer'а — словарь фолдов, где для каждой части доступны `X`, `y` и индексы `t0`.

---

## 1. Input Normalization

Перед извлечением признаков применяется **Instance Normalization** по каждому каналу внутри временного ряда.

Нормализация выполняется:

* независимо для каждого примера,
* по временной оси,
* отдельно для каждого канала.

Цели:

* уменьшить влияние масштаба и сдвига,
* стабилизировать обучение линейных экстракторов,
* улучшить обобщающую способность модели.

После нормализации форма тензора сохраняется:

`X_norm ∈ R^{B × L × C}`

---

## 2. Temporal Clustering Module (TCM)

### Назначение

TCM предназначен для извлечения временных признаков из рядов с **несколькими режимами поведения** (разные динамики, паттерны, состояния).

Вместо одного универсального экстрактора DUET использует:

* набор специализированных линейных экстракторов,
* механизм маршрутизации, выбирающий (мягко) подходящий экстрактор для каждого временного сегмента.

---

### 2.1 Patch Construction

Нормализованный временной ряд разбивается на временные патчи длины `patch_len`.

* число патчей: `N = L / patch_len`
* форма патчей:
  `X_patches ∈ R^{B × N × patch_len × C}`

Каждый патч интерпретируется как локальный временной сегмент с относительно однородной динамикой.

---

### 2.2 Time Series Decomposition

Для каждого патча выполняется декомпозиция временного сигнала на:

* `trend` компоненту (медленные изменения),
* `seasonal` компоненту (периодические/колебательные структуры).

После декомпозиции:

* `X_trend ∈ R^{B × N × patch_len × C}`
* `X_seasonal ∈ R^{B × N × patch_len × C}`

---

### 2.3 Distribution Router (Temporal Routing)

Для каждого патча извлекается компактное представление его распределения.

Роутер оценивает принадлежность патча к одному из `K_t` **временных кластеров**.

Результат маршрутизации:

* soft-веса принадлежности патча к каждому кластеру,
* веса нормированы по кластерной размерности.

Форма весов маршрутизации:

`W_t ∈ R^{B × N × K_t}`

---

### 2.4 Linear Pattern Extractors

Для каждого временного кластера используется собственный **linear-based pattern extractor**.

Каждый экстрактор:

* принимает объединённое представление `trend + seasonal`,
* извлекает признаки временной динамики,
* работает одинаково для всех каналов (channel-independent параметризация).

Выход каждого экстрактора:

`E_k ∈ R^{B × N × C × d_model}`

---

### 2.5 Mixture of Extractors

Итоговые temporal features формируются как взвешенная сумма выходов всех экстракторов:

* веса задаются `W_t`,
* агрегация выполняется по кластерной размерности.

Выход TCM:

`Z_t ∈ R^{B × N × C × d_model}`

Этот тензор содержит временные признаки для каждого патча и каждого канала с учётом временной неоднородности.

---

## 3. Channel Clustering Module (CCM)

### Назначение

CCM предназначен для моделирования структуры межканальных зависимостей и подавления шумовых связей.

Ключевые особенности:

* анализ в **частотной области**,
* обучаемая метрика расстояния между каналами,
* soft-кластеризация каналов,
* обязательное разреживание (sparsification).

---

### 3.1 Frequency Transformation

Для каждого канала временной ряд переводится в частотную область с помощью FFT по временной оси.

Амплитудный спектр имеет форму:

`X_freq ∈ R^{B × F × C}`

где `F ≈ L / 2`.

---

### 3.2 Channel Embedding

На основе спектра для каждого канала формируется компактное embedding:

`H_c ∈ R^{B × C × d_c}`

Это embedding отражает частотные характеристики канала.

---

### 3.3 Metric Learning and Soft Clustering

Межканальные расстояния вычисляются через обучаемую метрику (Mahalanobis-тип).

Каналы мягко распределяются по `K_c` кластерам.

Форма assignment-векторов:

`A_c ∈ R^{B × C × K_c}`

---

### 3.4 Channel Mask Matrix

На основе soft-кластеризации строится **channel mask matrix**, отражающая полезность каналов друг для друга:

`M ∈ R^{B × C × C}`

Матрица:

* симметрична,
* кодирует относительную важность межканальных связей.

---

### 3.5 Sparsification

Для подавления шумовых связей применяется разреживание:

* для каждого канала сохраняются только наиболее значимые связи (top-k или порог),
* остальные элементы маски обнуляются.

После этого `M` остаётся пригодной для дифференцируемого обучения.

---

## 4. Fusion Module (FM)

### Назначение

Fusion Module объединяет:

* temporal features из TCM,
* channel mask matrix из CCM,

в единое представление временного ряда.

---

### 4.1 Fusion Inputs

* temporal features:
  `Z_t ∈ R^{B × N × C × d_model}`

* channel mask:
  `M ∈ R^{B × C × C}`

---

### 4.2 Masked Fusion

Fusion реализуется как masked attention или masked channel mixing.

Основная идея:

* признаки каналов смешиваются только по разрешённым межканальным связям,
* маска `M` ограничивает распространение информации.

После fusion канальная размерность агрегируется.

Результат fusion:

`Z ∈ R^{B × N × d_model}`

---

## 5. Classification Head

Classification head агрегирует информацию по временной оси и формирует предсказание класса.

Типичный pipeline:

1. Temporal aggregation (mean / attention / pooling) по размерности `N`.
2. Получение глобального представления временного ряда:
   `Z_global ∈ R^{B × d_model}`.
3. Линейная проекция или MLP для получения логитов.

Выход модели:

`logits ∈ R^{B × K}`

Softmax применяется только на этапе инференса или внутри функции потерь.

---

## Training

DUET для классификации обучается end-to-end.

Типичная функция потерь:

* Cross-Entropy Loss.

Градиенты распространяются через:

* Classification Head → Fusion Module → TCM и CCM.

Это позволяет:

* TCM учиться корректно маршрутизировать временные режимы,
* CCM — формировать такие межканальные маски, которые действительно помогают различать классы.

---

## Summary

DUET для классификации сохраняет ключевые архитектурные принципы оригинальной модели:

* **TCM** моделирует временную неоднородность,
* **CCM** выявляет структуру межканальных связей,
* **Fusion Module** объединяет оба представления через masked fusion.

Единственное концептуальное отличие от forecasting-версии — **трактовка итогового представления**:

* вместо декодирования временного горизонта модель формирует **глобальное представление временного ряда**, используемое для классификации.

Любая реализация, в которой отсутствует реальная temporal clustering, channel clustering или masked fusion, формально может напоминать DUET, но логически ей не соответствует.
