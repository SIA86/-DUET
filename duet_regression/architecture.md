# Architecture: DUET (Dual Clustering Enhanced Time Series Forecasting)

## Overview

DUET — архитектура для долгосрочного прогнозирования многомерных временных рядов, ориентированная на два ключевых источника сложности:

1. **Временная неоднородность** — разные сегменты временного ряда могут подчиняться разным распределениям и динамикам.
2. **Сложные межканальные зависимости** — часть связей между каналами полезна для прогноза, часть является шумовой.

Для решения этих проблем DUET использует **двойную кластеризацию**:

* кластеризацию по времени (Temporal Clustering),
* soft-кластеризацию каналов (Channel Clustering) в частотной области,

и объединяет результаты через модуль masked fusion.

---

## Problem Definition

На вход подаётся окно многомерного временного ряда:

* входной тензор:
  `X ∈ R^{B × L × C}`

где
`B` — размер батча,
`L` — длина входного окна,
`C` — число каналов (переменных).

Задача модели — предсказать значения на горизонте `H`:

* выходной тензор:
  `Ŷ ∈ R^{B × H × C}`

---

## High-Level Pipeline

Архитектура DUET состоит из следующих этапов:

1. Нормализация входных данных
2. Temporal Clustering Module (TCM)
3. Channel Clustering Module (CCM)
4. Fusion Module (FM)
5. Forecast Head

Все модули обучаются end-to-end.

---

## 1. Input Normalization

Перед извлечением признаков применяется **Instance Normalization** по каждому каналу внутри входного окна.

Нормализация выполняется независимо для каждого элемента батча и каждого канала, по временной оси.

Цели:

* уменьшить различия распределений между train и test,
* стабилизировать линейные экстракторы,
* улучшить обобщающую способность модели.

На выходе этого этапа сохраняется тензор формы:

`X_norm ∈ R^{B × L × C}`

---

## 2. Temporal Clustering Module (TCM)

### Назначение

TCM предназначен для моделирования временных рядов с несколькими режимами поведения (seasonal shifts, trend changes, regime switching).

Вместо одного универсального экстрактора DUET использует:

* набор специализированных экстракторов,
* механизм маршрутизации (router), выбирающий подходящий экстрактор для каждого временного сегмента.

---

### 2.1 Patch Construction

Нормализованный ряд разбивается на неперекрывающиеся временные патчи длины `patch_len`.

* число патчей: `N = L / patch_len`
* форма патчей:
  `X_patches ∈ R^{B × N × patch_len × C}`

Каждый патч рассматривается как локальный временной сегмент.

---

### 2.2 Time Series Decomposition

Для каждого патча выполняется декомпозиция на две компоненты:

* `trend` — медленно меняющаяся составляющая,
* `seasonal` — колебательная составляющая.

После декомпозиции:

* `X_trend ∈ R^{B × N × patch_len × C}`
* `X_seasonal ∈ R^{B × N × patch_len × C}`

---

### 2.3 Distribution Router (Temporal Routing)

Для каждого патча извлекается компактное представление его распределения.

Роутер оценивает принадлежность патча к одному из `K_t` латентных временных кластеров.

Логика роутера:

* вход: агрегированное представление патча,
* выход: soft-веса маршрутизации.

Форма весов маршрутизации:

`W_t ∈ R^{B × N × K_t}`

Для каждого патча сумма весов по `K_t` равна 1.

---

### 2.4 Linear Pattern Extractors

Для каждого временного кластера используется собственный **linear-based pattern extractor**.

Каждый экстрактор:

* принимает объединённое представление `trend + seasonal`,
* извлекает временные признаки линейным или слабонелинейным способом.

Выход каждого экстрактора имеет форму:

`E_k ∈ R^{B × N × C × d_model}`

---

### 2.5 Mixture of Extractors

Итоговые temporal features вычисляются как взвешенная сумма выходов всех экстракторов:

* веса задаются `W_t`,
* агрегация происходит по размерности кластеров.

Результат работы TCM:

`Z_t ∈ R^{B × N × C × d_model}`

Этот тензор содержит временные признаки для каждого патча и каждого канала, уже с учётом временной неоднородности.

---

## 3. Channel Clustering Module (CCM)

### Назначение

CCM предназначен для выявления полезных межканальных связей и подавления шумовых зависимостей.

Ключевые особенности:

* работа в **частотной области**,
* использование **learnable metric**,
* **soft-кластеризация каналов**,
* обязательное разреживание связей.

---

### 3.1 Frequency Transformation

Для каждого канала временной ряд переводится в частотную область с помощью FFT по временной оси.

Результат (амплитудный спектр):

`X_freq ∈ R^{B × F × C}`

где `F ≈ L / 2`.

---

### 3.2 Channel Embedding

Для каждого канала формируется компактное embedding на основе спектра.

После агрегации и проекции:

`H_c ∈ R^{B × C × d_c}`

---

### 3.3 Metric Learning and Soft Clustering

Межканальные расстояния вычисляются с использованием обучаемой метрики (Mahalanobis-тип).

Каналы мягко распределяются по `K_c` кластерам.

Форма assignment-векторов:

`A_c ∈ R^{B × C × K_c}`

---

### 3.4 Channel Mask Matrix

Channel mask matrix формируется как функция soft-кластерных назначений.

Итоговая маска:

`M ∈ R^{B × C × C}`

Матрица:

* симметрична,
* отражает относительную полезность канала `j` для канала `i`.

---

### 3.5 Sparsification

Для подавления шума применяется разреживание:

* сохраняются только top-k связей для каждого канала,
* остальные веса обнуляются.

После sparsification маска остаётся дифференцируемой (или квазидифференцируемой).

---

## 4. Fusion Module (FM)

### Назначение

Fusion Module объединяет:

* temporal features из TCM,
* channel mask matrix из CCM.

Цель — разрешить обмен информацией между каналами **только по разрешённым связям**.

---

### 4.1 Fusion Inputs

* temporal features:
  `Z_t ∈ R^{B × N × C × d_model}`

* channel mask:
  `M ∈ R^{B × C × C}`

---

### 4.2 Masked Fusion

Fusion реализуется как masked attention или masked channel mixing.

Общая идея:

* признаки каналов смешиваются с учётом `M`,
* связи с нулевыми или малыми весами не участвуют в обмене информацией.

После fusion канальная размерность агрегируется.

Результат fusion:

`Z ∈ R^{B × N × d_model}`

---

## 5. Forecast Head

Forecast head преобразует fused features в прогноз на горизонт `H`.

Типичная реализация:

* линейная проекция или MLP,
* независимый прогноз для каждого канала.

Выход:

`Ŷ ∈ R^{B × H × C}`

Если применялась нормализация, выполняется обратное преобразование (denormalization).

---

## Training

DUET обучается end-to-end.

Типичные функции потерь:

* Mean Squared Error (MSE),
* Mean Absolute Error (MAE).

Градиенты распространяются через:

* Forecast Head → Fusion Module → TCM и CCM.

Это позволяет:

* TCM адаптировать маршрутизацию временных режимов,
* CCM формировать channel mask, оптимальную именно для задачи прогнозирования.

---

## Summary

DUET — это архитектура с жёстким разделением ответственности:

* **TCM** отвечает за временную неоднородность,
* **CCM** — за структуру межканальных связей,
* **Fusion Module** — за согласованное объединение этих двух представлений.

Корректная реализация DUET требует:

* реальной temporal кластеризации,
* реальной channel soft-кластеризации в частотной области,
* обязательного masked fusion.

Упрощение или пропуск любого из этих элементов приводит к архитектуре, которая формально похожа на DUET, но логически ей не соответствует.
